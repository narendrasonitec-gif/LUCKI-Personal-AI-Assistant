# LUCKI AI

### Your Personal AI Voice Assistant

## About the Project
Lucki AI is an intelligent personal AI assistant developed using Python and Google's Gemini AI. It is designed to interact with users through voice and text, understand commands, and help perform everyday tasks.

## Key Features
- AI-powered conversations
- Voice input and voice responses
- Speech recognition
- Text-to-speech
- Application launching
- Google search
- Modern animated user interface

## Tech Stack
- Python
- Google Gemini API
- Speech Recognition
- Edge TTS
- Pygame
- python-dotenv
